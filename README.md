## 🗂️ Projetos

### 🧪 SauceDemo
Meu primeiro projeto no qual utilizei testes manuais realizados na aplicação de e-commerce fictícia SauceDemo, utilizada como ambiente de prática. Inclui casos de teste estruturados e exploração das funcionalidades da aplicação com apoio do Chrome DevTools.

**Destaques:**
- Casos de teste documentados
- Uso do Chrome DevTools para investigação de comportamento da aplicação

📁 [Acessar pasta do projeto](./SauceDemo)

---

### 🍕 MegaPizza
Testes exploratórios realizados no site de e-commerce de uma pizzaria da minha cidade (Mega Pizza SL). Foram identificados e documentados 7 bugs em diferentes níveis de severidade, com relatório em Markdown e Excel.

**Destaques:**
- Testes exploratórios em ambiente de produção real
- Documentação de bugs com nível de severidade
- Relatórios em dois formatos (Markdown e Excel)

📁 [Acessar pasta do projeto](./MegaPizza)

---

### 🎮 Steam
Bug encontrado na Steam Community Market: um problema de persistência de filtros. O bug foi documentado com vídeo (Loom) e um ticket de suporte pronto para envio, simulando um report real para a equipe de desenvolvimento.

**Destaques:**
- Bug real encontrado em produção
- Evidência em vídeo (Loom)
- Ticket de bug pronto e enviado para a própria Steam.

📁 [Acessar pasta do projeto](./Steam)
